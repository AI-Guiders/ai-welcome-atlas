# Карта арсенала на старте сессии (v1)

Агент на старте сессии получает список инструментов JSON-схемами и пользовательский AGENTS.md (обычно — про память/KB). **Схема ≠ карта местности**: без нарратива «что зачем» дефолт у агента один — привычный Bash. Эта заметка — карта того, что просыпается вместе с тобой.

## Четыре слоя, которые у тебя уже есть

| Слой | Что это | Брать для |
|---|---|---|
| **KB / память** (agent-notes MCP) | hot-контекст, роутер, knowledge/ | контекст задачи, запись выводов |
| **Штатный Bash харнесса** | одна оболочка, cwd сессии, фон с уведомлениями | разовые команды, короткие прогоны |
| **Терминальный хабатат** (terminal-mcp) | именованные вкладки, у каждой свой cwd/shell; history + rerun; `background: true` с авто-будильником; durable-джобы (переживают рестарт MCP); kill/close по вкладке | долгие и параллельные процессы: сборка в одной вкладке, сервер в другой, тесты в третьей |
| **CDP-плоскость** (cdp-* тулы) | свой мир (корень `D:\cdp-service.staging\<date>_<id>`) + IDE: build/test/debug с брейкпоинтами, buffer редактора, диагностики | IDE-работа по проекту, код-задачи |

## Правило выбора

1. **Разовая команда** → Bash. Ближе к сессии, выдача прямо в контекст.
2. **Долго / параллельно / надо пережить рестарт** → вкладки терминального хабатата с фоном и будильником.
3. **Проект, код, сборка, отладка** → CDP-плоскость: `cdp_open` задаёт session defaults, дальше build/test/debug без повторных путей.

## Витрина и подвал: видимые 60 — не весь арсенал

CDP экспонирует хосту ровно **60 тулов** — это витрина. За витриной — доменные семейства, которые выдаются **фазовой палитрой** `cdp_tools` (shortlist по phase/object/intent, со скорами и метками cost/risk): `memory_world_`, `memory_project_`, `debug_`, `build_`, `roslyn_`, `git_`, `codebase_index_`, `anui_`.

Проверено 2026-10-26: в фазе recall+object=kb палитра отдала 8 тулов `memory_world_*` — включая `recall_knowledge` и `radius_gate_check`, — **ни одного из видимых 60**. Агент, не знающий о палитре, считает витрину всем складом. Плюс `cdp_mcp`-outlet монтирует гостевые серверы, чьи тулы в ListTools хоста вообще не попадают.

Правило: **входишь в новую фазу — спроси палитру** (`cdp_tools` по своим phase/object/intent), а не полагайся на витрину.

## Почему карта нужна: замкнутый кружок самоописания

Самоописание у среды есть — `cdp_man` (TOC всей CDP-поверхности), `cdp_man tool=first_contact`, `go=onboard_desk`. Но чтобы вызвать мануал, нужно о нём узнать; а в голом списке схем он ничем не выделен. Нарратив должен прийти контекстом при старте (строчка в AGENTS.md / автозапуск first_contact) — иначе арсенал открывается на N-м часу по подсказке оператора.

## Случай из практики (2026-10-26)

Сессия «сканы приговора → апелляционная жалоба DOCX» отработана целиком штатным Bash: Pillow для кропа сканов, docx-js для документа, Word через COM + PyMuPDF для рендера, winget для ImageMagick. Терминальный хабатат и CDP-шелл открыты на седьмом часу по подсказке оператора («зафига тебе Git Bash, если есть terminal mcp?»). Квирки того дня — `work/projects/door-to-singularity/cascade-ide/note-zcode-harness-quirks.md` §6–7 (арсенал по умолчанию закрыт; winget → UAC оператору; PATH подхватывают только новые процессы).
